# NEXUS-E

Nigerian Environmental Expertise Exchange. Registration site for the Benin 2026 conference (PRD Phase 1).

Stack: React, TypeScript, Vite, Tailwind CSS v4, Supabase (Postgres, Auth, Row Level Security).

## Run locally

```bash
npm install
cp .env.example .env.local   # then fill in your Supabase values
npm run dev
```

Checks used before every commit:

```bash
npm run lint && npm run typecheck && npm run build
```

## Routes

| Route | Purpose |
| --- | --- |
| `/` | Welcome and how it works |
| `/register` | Three screen registration form, progress saved in sessionStorage |
| `/registered` | Confirmation with Expert ID and copy button |
| `/admin` | Admin sign in, dashboard, search, filters, record detail, CSV export |

## Backend

SQL lives in `supabase/migrations`. Run the files in order in the Supabase SQL editor (or with the Supabase CLI).

- `experts` table, `expert_id_seq` sequence and the `NEX-000001` ID default. IDs are generated by the database.
- Unique indexes on lower-cased email and normalised phone number.
- Row Level Security is on for every table. The public role has no direct access to any table.
- `register_expert(payload jsonb)` is a `security definer` function and the only thing the public can call. It validates, checks the honeypot, applies a generous rate limit, inserts the record and returns the Expert ID. Duplicates come back as `duplicate_email` or `duplicate_phone`.
- Admin reads need two things: a signed in user and a row in `public.admins` with the same email. Being signed in alone is not enough. See `supabase/seed_admin.example.sql`.

## Hooks left for later

- **Confirmation email:** `register_expert` queues a row in `public.email_outbox` (status `pending`) for each registrant with an email. A later Edge Function or scheduled job should send the email, then set `status = 'sent'`. No email is sent in this pass.
- **Cloudflare Turnstile:** `src/components/Turnstile.tsx` is the slot for the widget, and `supabase/migrations/..._rls_and_rpc.sql` marks where to verify the token. Set `VITE_TURNSTILE_SITE_KEY` when ready.
- **QR code:** not part of this pass. Point it at a redirect you control so the destination can change after printing.
